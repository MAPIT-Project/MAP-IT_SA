# MAPIT_base_METU

Classical RAG-based first step fo MAPIT RAG-LLM.


---

Currently reads the project names and objectives from the projects.csv.
Currently, projects.csv should be under the same directory with the script or the path of the csv file should be updated in the script.

---

Two versions: with llama and with Mistral.
llama-based version requires ollama and llama 3.2 installed at the local computer.

Prompts are slightly adjusted according to llms.
