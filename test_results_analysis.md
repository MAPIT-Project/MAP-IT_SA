## Issues Requiring Fixes

### Issue 1: Raw Document Fragments in Response (Q5)
**Priority: HIGH**

The response for Q5 contains raw, truncated document text instead of a synthesized answer. The quality filter should detect:
- Sentences that start mid-word
- Text mentioning "Section X.Y.Z" or "Article X.Y"
- Truncated content patterns

**Suggested Fix**:
Add to `_is_poor_quality_answer()`:
```python
# Truncated document patterns
"participation is considered essential for implementing",
"reject tenders for supply contracts",
"affiliated entities are eligible",
```

### Issue 2: Vague Redirects Instead of Answers (Q8, Q14)
**Priority: MEDIUM**

Some responses redirect users to documents instead of extracting and presenting the information.

**Suggested Fix**:
- Ensure Work Programme and Programme Guide content is properly indexed
- Improve document chunking to capture full sections on eligibility and page limits

### Issue 3: Inconsistent Confidence Scores
**Priority: LOW**

Some excellent responses show confidence 0.0 while poor responses show higher confidence.

**Suggested Fix**:
- Review confidence calculation in ToolAwareAgent
- Confidence should reflect answer quality, not just search success
