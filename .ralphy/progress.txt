## 2026-01-21: Prompt 001 - Horizon Europe Structure (FIX IF NEEDED)

### Task Completed
Fixed actionability issue that was causing scores below 85. Score improved from 80 to 91.

### Problem Identified
The previous evaluation showed:
- **Overall Score**: 80/100 (NEEDS_REVIEW)
- **Actionability Score**: 0-2/10 - No links to official resources

### Root Cause Analysis
The agent was using built-in knowledge to answer programme structure questions without calling the `get_programme_info` tool. Even when calling the tool, the response lacked actionable links.

### Fix Implementation (1 attempt - successful)

#### Files Modified:
1. **`app/services/tools/multi_programme_search.py`**:
   - Added `resources` dict with official EU portal links for all programmes
   - Added `guidance` field with actionable "Getting Started" guidance including markdown links
   - Enhanced `get_programme_info_execute()` to return `actionable_guidance` at top level

2. **`app/services/agents/tool_aware_agent.py`**:
   - Added actionable links section to `BUILT_IN_KNOWLEDGE` with instructions to always include when explaining programme structure
   - Updated `get_programme_info` tool description to indicate it returns actionable guidance
   - Added "ALWAYS include actionable links" guideline to Response Guidelines section

### Fix Details

Added to BUILT_IN_KNOWLEDGE:
```markdown
### Official Resources (ALWAYS include when explaining programme structure)
🎯 **Getting Started with Horizon Europe:**
• Register on [EU Funding & Tenders Portal](https://ec.europa.eu/info/funding-tenders/opportunities/portal/screen/home)
• Review the [Work Programmes](https://ec.europa.eu/info/funding-tenders/opportunities/portal/screen/how-to-participate/reference-documents;programCode=HORIZON)
• Check eligibility via [How to Participate](https://ec.europa.eu/info/funding-tenders/opportunities/portal/screen/how-to-participate/how-to-participate/1)
• Find partners using [Partner Search](https://ec.europa.eu/info/funding-tenders/opportunities/portal/screen/how-to-participate/partner-search)
• Browse [Call Calendar](https://ec.europa.eu/info/funding-tenders/opportunities/portal/screen/opportunities/calls-calendar)
```
